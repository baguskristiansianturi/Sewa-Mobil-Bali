# Sewa Mobil Bali — Landing Page Demo

Demo portofolio untuk koleksi website Bagusin. Halaman menggunakan satu file `index.html` dengan CSS dan JavaScript di dalamnya agar mudah dipelihara dari HP.

## Status
- Desain landing page responsif: desktop dan mobile
- Navigasi mobile
- Filter kategori kendaraan
- Formulir tanggal/lokasi/jenis layanan dengan validasi dan ringkasan simulasi
- Tidak ada pengiriman data, backend, atau koneksi WhatsApp
- Harga, kategori, foto, dan detail kendaraan adalah contoh, bukan penawaran rental aktif

## Aktifkan GitHub Pages
1. Buka repository ini di GitHub.
2. Masuk ke **Settings → Pages**.
3. Di **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
5. Tunggu beberapa menit. URL publik akan muncul di halaman **Settings → Pages**.
6. Buka URL tersebut di HP dan uji menu, filter mobil, tanggal, formulir, dan semua tautan.

Jika GitHub Pages belum aktif, file website sudah tersimpan di branch `main`, tetapi website publik belum dapat dianggap terbit sampai statusnya muncul di Settings → Pages.

## Checklist uji
- [ ] Tidak ada scroll horizontal di layar HP
- [ ] Menu mobile bisa dibuka dan navigasi bekerja
- [ ] Filter kendaraan mengubah kartu yang terlihat
- [ ] Tanggal selesai tidak lebih awal dari tanggal mulai
- [ ] Ringkasan menyatakan bahwa data tidak dikirim
- [ ] Harga dan layanan demo tidak disalahartikan sebagai reservasi nyata
- [ ] Foto dan font eksternal termuat

## Berikutnya
Setelah URL Pages aktif dan diuji, masukkan proyek ke koleksi Bagusin sebagai **Rental Mobil — Landing Page Demo**. Jangan mengklaim pemesanan sungguhan sebelum menambahkan kontak resmi dan sistem pemesanan yang benar-benar bekerja.
